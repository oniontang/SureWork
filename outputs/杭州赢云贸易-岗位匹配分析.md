## 三、岗位解读：他们到底要什么人

把 JD 翻译成业务语言：一家跨境电商公司，要用 AI 编程工具（Cursor / Claude Code / Copilot）快速做出——内部业务系统、管理后台、数据工具、MVP、AI 应用；加分项 6「大规模爬虫 / 数据采集 / 反爬 / 清洗」几乎点名要做**选品 / 竞品 / 价格 / Listing 数据采集**。

核心画像**不是**「手写高质量代码的资深架构师」，而是「**会用 AI 把模糊需求快速拆成能上线的功能、并能人工审查 AI 代码**」的高杠杆交付者。

## 四、你的匹配度（逐条对照）

**强命中（差异化优势）**

- **Vibe Coding 理念**：你在教这门课，对 Prompt / 上下文管理 / 小步迭代 / 人工审查 / 测试闭环的理解比多数应聘者深。
- **Prompt 与 AI 工具链**：Cursor / Claude Code 实操 + AIGC 批量出图 + 提示词工程。
- **AI 应用 / Agent**：FDE 智能体、DeepAgents / LangChain、支付宝智能体涌现奖参赛、SPARC 平台 → 命中 RAG / MCP / Agent / Function Calling。
- **爬虫 / 数据采集 / 反爬**：小红书 / 抖音 / 语雀 / 静态站抓取、302 反爬、登录态读 `__INITIAL_STATE__`、图片 CDN → **直接命中加分项 6**。
- **前端栈**：React / Vue / Node.js / Vite（GSAP、MPA）→ 命中技术栈的一半。
- **懂跨境电商业务**：家具外贸独立站（北美 / Dropshipping）、网站变现 → 对这家跨境公司是稀缺的「懂业务的开发」。
- **交付 / 测试 / 部署意识**：多角色后台 + 权限守卫、Edge 无头截图 grep 验证闭环、云函数代理 / 定时同步、Pages 发布 → 命中「审查 AI 代码 / 自动化测试 / 排查部署上线」。

**主要差距（需补 / 需话术）**

- **Python / FastAPI / PostgreSQL / Redis 生产级后端深度**：你偏前端 + Node + 脚本，这套后端工程栈尚未成体系。
- **Docker / Linux / Nginx / 消息队列** 等运维组件：未明确。
- **「3-5 年真实开发经验 / 完整企业交付履历」**：你多为自由项目 / 课程 / 个人品牌 / FDE，HR 可能追问稳定在职雇主背书。
- **学历**：JD 本科优先（样本 100% 本科），需确认。
- **资历错位风险**：你的能力 / 定位可能高于这个 15-20K 的执行型岗，别被「全栈」名头压价。

**匹配度结论：约 75-80%。** 理念、AI 工具链、爬虫、前端、业务理解几乎满配；短板集中在 Python 后端工程栈与「企业在职履历」背书。

## 五、注意事项与风险（面试前务必核实）

1. **团队真实性**：参保仅 3 人 vs 招聘量 82 / 规模少于 50。核实：技术团队实际几人、你向谁汇报、这岗是新建还是替补、是否外包 / 驻场 / 项目制、试用期长度与考核。
2. **合同与社保主体**：注册经营范围无软件开发。核实：劳动合同签赢云贸易还是关联技术公司、社保公积金缴纳地与基数、是否走第三方。
3. **公司稳健性**：成立 3 年、控股平台 2026 才设、跨境电商自建 AI 团队属重投入。看盈利模式 / 现金流 / 团队留存（职友集 44 条点评可查），问清「技术投入是长期战略还是试水」。
4. **岗位边界**：Vibe Coding 岗与 Python 岗共用代码 PY01，职责可能模糊。问「入职前 3 个月要交付什么、现有系统 / 数据长什么样、有没有测试和上线环境」。
5. **薪资定位**：15-20K 在杭州 3-5 年全栈里偏低，且低于其自身 AI Agent Java 岗（20-40K）。你 7 年经验可争取更高，或明确晋升 / 项目奖金。
6. **叙事准备**：想好「为什么贸易公司做 AI」「你为什么从讲师 / 自由项目回到企业岗」，把「教 Vibe Coding + 懂跨境 + 能爬数据」作为核心卖点，而非纯码农。
