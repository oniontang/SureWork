生成日期：2026-10-09 ｜ 依据：四项公开渠道核查（支付通道 / 资质 / 灵工税务 / 竞品费率口碑）+ 闲鱼官方披露数据

# 第一部分　一页版定位修订

## 1.1 结论先行

原定位（双边担保接单平台）**不建议按现方案推进**。核查后的三条硬阻碍不是钱能解决的，而是组织形态层面的：

| 假设（原方案） | 核查结果 | 影响等级 |
|---|---|---|
| 微信支付服务商 + 电商收付通分账，4–6 周走完 | 平台主体必须是企业普通服务商；分账上限默认 30%、资金冻结 180 天；实际平台资质审核 1–2 个月起 | 致命（资金流向设计不成立） |
| 上线前办 ICP + EDI 即可 | EDI 要求公司主体 + 注册资本≥100 万 + 3 名人员社保；交易/招聘类目另触发《人力资源服务许可证》（要求 3 名专职人员）；上线后每半年向市监报送经营者信息 | 致命（单人公司扛不住） |
| 从业者收入"接入灵工平台代征"是可插拔模块 | 平台自身即为报送/扣缴义务主体（810 号令按季报送，违规最高罚 50 万）；委托代征通道 2024–2026 大面积收紧 | 高（义务外包不出去） |

差异化叙事同时塌了：「资金全程托管、验收后付款」是猪八戒官方规则原文（含与你方案一字不差的"验收申请 7 天雇主无操作自动通过"）；一品威客 2026-07-01 起做"全链托付"（平台统一自营承接、款项全额托管、先验收再放款）。

## 1.2 新定位（建议验证的切口）

一句话：**帮企业把付给个人的这笔 AI 服务费，做得干净、可追溯、拿得到票。**

- 付费方是企业，不是从业者。企业有三样东西个人没有：预算、审计压力、对烂尾的恐惧。个人侧永远是流量成本，企业侧才是收入来源。
- 卖的是"过程合规 + 交付见证"，不是"撮合流量"：合同与验收标准模板、资金走现成持牌通道托管、发票与完税凭证、全流程留痕的证据链、争议时的第三方意见。
- 不碰资金池、不做在线达成交易 → 有机会把 EDI 与人力许可这两个坑绕开（此点必须先向税务师与律师确认，见 1.5）。
- 抽佣叙事换成成本叙事：猪八戒/一品威客真正被骂的是 5000 元诚信保证金、4399 元企微会员、CPC 推广金（无套餐 2 元起竞、日预算≥100 元）、退款不退服务费、ESN 派单到手仅 60%–70%。你不需要"佣金更低"，你需要"零保证金、零推广、零会员、按项目单次收费"。

## 1.3 为什么是现在（政策窗口）

财政部/税务总局 2026 年 28 号公告：**2026-11-01 起，企业向自然人支付设计、软件、咨询等七类智力服务费须代扣增值税，按次起征点 1000 元**；平台内从业人员由平台代办扣申报。

距今约三周。这条规定给所有"找个人干活、转账了事"的中小企业财务突然布置了一项他们不会做的任务。这是政策制造的付费理由，比"我们平台有担保"硬得多。注意它是双面的：机会在于企业需要有人替他把这件事办顺；风险在于你若以平台身份组织这些人干活，你可能是那个代办扣缴申报的主体。

需求总量侧的佐证（闲鱼官方披露，IT之家 2026-07-29）：2026 上半年 AI 服务订单 981.6 万单、同比 +157%；近 500 万用户购买、+98%；卖家月均成交 897 元；品类构成 AI 技能接单 45.1%、教程 8.1%、模板与工作流 6.6%；增速最快为 AI 编程与建站 +1732%、AI 漫剧 +1425%、AI 办公 +264%。

同一组数据给出边界：低价长尾已被零成本的闲鱼吃干净，去那儿抢单毫无胜算；空位在高客单（几万到几十万的 AI 编程与建站类项目），那也正是验收与合规最值钱的一段。

## 1.4 明确不做什么（边界）

1. 不做双边撮合市场：不建抢单大厅、不做投标竞价、不做信用榜单。
2. 不碰资金池、不做资金归集：托管与分账一律用现成持牌通道，或者干脆不碰钱（只出流程与凭证）。
3. 不做小程序交易类目：不把交易搬到微信/支付宝小程序内完成，避免 EDI 与人力许可触发。
4. 不做"低佣金平台"叙事：对外不讲抽成比例，只讲"一单多少钱、含哪些动作"。
5. 一期不做设计/剪辑品类：该区间被 AI 替代与闲鱼低价双重挤压。只做 AI 编程与建站、智能体搭建、AIGC 内容体系三类高客单交付。

## 1.5 决策前必须问专业机构的问题（不可自行推断）

| # | 问题 | 问谁 |
|---|---|---|
| 1 | 只做"付款通道 + 合同验收见证"、不在平台内完成交易撮合，是否仍触发 EDI 许可 | 资质代办 + 通管局 12381 咨询 |
| 2 | 28 号公告下，企业向个人支付 AI 开发/咨询费的具体扣缴与申报口径、按次起征点如何适用 | 税务师事务所 |
| 3 | 灵工综合费率 6%–10% 与 11-01 起的代扣增值税是否重复计税，能否叠加 | 税务师事务所 |
| 4 | 若认定"人活是我介绍来的"，居间撮合方在 810 号令下的报送义务边界到哪里 | 律师（平台合规方向） |
| 5 | 个体工商户主体能否承接此类服务并开具发票，还是必须有限公司 | 会计师 + 市监 |

# 第二部分　访谈脚本（补齐唯二查不到的两项）

执行要求：一对一、20 分钟内、只问行为不问意愿（不问"你会不会用"，只问"上一次你怎么做的"）。每家/每人一行记录，禁止访谈后凭印象补。

## 2.1 企业卷（目标 10 家：中小微企业主 / 市场或技术负责人）

A 组　现状行为（拿基线）

1. 过去一年，你们找过公司以外的人干活吗？做什么、多少钱、怎么找到的？
   → 判据：能说出具体的"找人渠道"，否则该企业不是目标客户。
2. 那笔钱最后是怎么付的？微信转账、对公、还是走了什么平台？
   → 判据：走对公 = 已有票据需求；私下转账 = 11-01 后新增痛点。
3. 拿到发票了吗？没拿到的话，这笔成本在账上怎么处理的？
   → 判据："财务让我别这么干了" = 强信号。

B 组　痛点强度（拿付费理由）

4. 那次交付里最不顺的一件事是什么？改了几轮？有没有最后不干了/不付款的情况？
   → 判据：说得出具体纠纷细节，且不只有价格抱怨。
5. 如果当时有个人帮你们把合同、验收标准、付款节奏、发票这套流程盯下来，你觉得值多少钱？按项目价百分比说。
   → 判据（关键）：**不要接受"挺好"，只接受数字**。≥3% 记为强意愿，1%–3% 记为弱意愿，<1% 或答不出记为无意愿。
6. 11 月起，公司付给个人的设计/软件/咨询费要代扣增值税，按次起征点 1000 元。你们财务知道这件事吗？
   → 判据（政策窗口验证，最重要）：**≥4/10 家表示"刚知道/完全不知道且在意"**，说明窗口为真；若普遍无感或已有成熟处理方案，窗口证伪。

C 组　行动测试（拿真单，不是拿好评）

7. 你们未来 60 天内有要外包出去的 AI 相关活吗？大概预算多少？
8. 我现在可以帮你把下一单这么办：合同 + 验收清单我来出，款走托管、验收后才放款、发票和完税凭证齐，收你 X 元（或 3%）。要不要现在就把这一单办起来？
   → 判据：**当场同意推进 = 1 分；"发我看看" = 0 分；拒绝 = 0 分**。

9. （给已找过外包的人）你为什么没在猪八戒/一品威客上做？知道它们要交 5000 元保证金吗？
   → 判据：验证"老平台口碑崩坏"是否真的把客户推到你的位置。

## 2.2 OPC 卷（目标 20 人：独立开发者 / AI 应用搭建者 / AIGC 内容生产者）

A 组　收入结构基线

1. 最近三个月，你的收入里私单占比多少？最大一单多少钱？客户从哪来？
   → 判据：若 100% 来自转介绍且月入≥3 万，他不是你的供给（他不需要平台，这是好消息也是坏消息：说明优质供给不缺单）。
2. 你现在一个月在"找单/维持单量"上花多少时间？花什么钱？（会员费、保证金、推广金各多少）
   → 判据：说得出具体支出金额者，才可能被"零保证金零推广"叙事打动。

B 组　痛点与跳单意愿（最重要，别怕听到坏消息）

3. 被赖过账吗？金额多少？最后怎么收场的？
   → 判据：≥1/3 有人经历过 = 担保需求为真。
4. 开票怎么办？你给客户开过票吗？自然人代开你知道流程吗？11 月之后的新规你清楚吗？
   → 判据：答不出者 = 你的服务有位置；已自行解决者 = 你在他身上没有价值。
5. 客户跟你说过"下次直接找你、别走平台，省手续费"吗？你怎么答的？
   → 判据（跳单压力测试核心）：**记录"我答应并真的私下走过"的人数**。

6. 假想场景：一个通道能帮你把尾款催收变成"对方不验收就自动放款"、还给你出完税凭证，代价是每单收 5%、客户觉得多花钱、并且你会被要求把客户和合同留在这个通道里。你第一年愿意把多少比例的单走它？
   → 判据（诚实阈值）：**第一年愿导流 ≥50% = 通过；<30% 视为模型不成立**。这一题是决定平台要不要做的题，别用礼貌答案糊过去。

7. 如果这个平台今天上线，把你微信里所有客户拉进来，你担心什么？
   → 判据：出现"客户被抢""数据被平台看到"= 供给侧真实阻力，需要设计隔离条款。

C 组　供给侧转介绍能力（他能不能当你的渠道）

8. 你认识的同行里，有几个是被验收和尾款折腾到不想接单的？我现在就做这件事，你给我介绍 3 个人聊聊，可以吗？
   → 判据：当场给出具体名字/联系方式者 ≥5/20，说明供给侧叙事有传播力。

# 第三部分　判据阈值与止损线

30 天验证的通过线（三条同时满足才继续投入）：

| 指标 | 通过线 | 不达标含义 |
|---|---|---|
| 企业访谈中"11 月新规刚知道且在意" | ≥ 4/10 | 政策窗口是想象的，付费理由不成立 |
| 企业愿付"过程合规 + 验收见证"比例 | ≥ 3 家给出 ≥3% | 单侧切口收入模型太薄，撑不住 |
| OPC 愿第一年导流 ≥50% | ≥ 6/20 | 供给忠诚度为零，任何双边形态都必死于跳单 |
| 30 天内出现 1 单真实试点成交 | ≥ 1 | 需求只存在于聊天里 |

任一指标落在 50% 以下：停，回到课程与自媒体主业。不要"再优化一版方案"。

反向止损（出现即收缩，不做解释）：

1. 任何一起因你代收/代付/见证而起的资金纠纷，且无法清晰切割责任；
2. 支付通道或资质任一项卡超过 8 周；
3. 5 个专业问题里 ≥3 项得到"该模式仍需 EDI 或人力许可"的答复。
